# RL-next component verification — 2026-09-22

## Scope

This is a verified **experimental component package**, not a new Minecraft runtime release. The original v0.3.1 Azalea/Folia application, bridge, rooms, launcher and native bot binaries have not been integrated with these components. Its live behaviour has not changed as a result of this work. The attached-distribution workspace became inaccessible during dependency-kit extraction; subsequent filesystem/command execution repeatedly failed with transport timeouts. GitHub Actions was used to compile and test the independent components instead. The cause of the workspace failure was not established.

Do not overwrite a working v0.3.1 installation with this package. No live Minecraft learning-speed improvement or advanced-skill mastery has been measured.

The final corrective changes reject two important false positives: an empty fragment cannot invent an unseen terminal transition; reset-supplied items or historical deposits cannot substitute for newly acquired output or current container stock.

## Five-seed reward-only synthetic PPO check

**This table is not a Minecraft benchmark.** It checks a categorical optimizer in an eight-context/four-action contextual bandit. The learner receives sampled rewards, not target-action labels. The environment's reward rule is used separately to calculate the final policy's exact expected return. No v0.3.1 baseline was run on this fixture, so these figures establish neither comparative speed nor the benefit of any individual modification.

Each seed used 120 policy updates, 256 samples per update, four epochs, and 30,720 environment samples. All policies started with expected return 0.25. The success threshold enforced by the executable was 0.90.

No guard retries occurred in the synthetic benchmark; forced retry/rollback paths are exercised by separate unit tests. This benchmark is too small and too simple to assess long-horizon exploration, learning retention in Minecraft, 32-client throughput, GUI skill reachability or multi-agent cooperation.
